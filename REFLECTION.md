# Reflection

This tip calculator is an AI-assisted implementation prepared with Codex. It combines an HTML interface, CSS styling and a separate JavaScript file for calculations and input validation. My understanding of the four Cursor tools is as follows.

Tab is useful for completing small pieces of code while typing, guided by nearby code or comments. Inline edit is appropriate for a selected change, such as fixing a typo in existing code or renaming a variable within one function. Ask is useful for understanding unfamiliar code and discussing edge cases without changing files. Agent is suited to a complete feature that requires coordinated changes across files, followed by review of those changes.

One part of the AI implementation that requires checking is whether invalid inputs produce understandable errors instead of misleading results.
